Это учебный проект на Python для геймификации процесса обучения.
## Как запустить проект
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Импортируйте database.backup в созданную вами базу данных.

   Этот бэкап работает только в PostgreSQL.
    
3. Запустите приложение:
   ```bash
   python app.py
   ```

## Используемые технологии
* Python
* Tkinter
* PostgreSQL
